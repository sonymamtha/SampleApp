# SampleApp

This is a sample application to show TV shows and their cast details.

## Features

- Fetches TV show data from a local JSON file (`src/assets/data.json`) via `HttpClient`
- Displays each TV show along with its cast members, sorted by birthday
- Search box to filter TV shows by name, with a message shown when no results are found
- Pagination for browsing through the list of TV shows

## Getting Started

Install dependencies:

```bash
npm install
```

Run the app:

```bash
npm start
```

Then open `http://localhost:4200` in your browser.

## Running Tests

```bash
npm test
```
